# Changelog

Every revision of the privacy policy, newest first. The extension version is
the release whose data handling the revision describes.

- Added section 9, "Legal basis and your rights" (DPDP Act 2023, GDPR).
- Added an email contact alongside GitHub issues.
- Added a table of contents, section anchors, a print stylesheet and this revision history.
- Repository: added `scripts/check-policy-sync.mjs`, GitHub Actions checks, LICENSE and this file.
